RAG agent

Ask about my work. An ML router, hybrid retrieval and an LLM agent answer from this page only, and you can watch every step.

checking for an LLM…

Pipeline. (1) A multinomial Naive Bayes classifier, trained in your browser on labelled questions, routes the query and flags off-topic ones. (2) BM25 and character-trigram search each rank 20 passages, merged with reciprocal rank fusion. (3) With an LLM available, Claude acts as an agent: it calls a search_portfolio tool as many times as it needs, then writes a cited answer. (4) A verifier deletes any citation to a passage that was never retrieved. Without an LLM, it returns the top passages word for word.
